# Tartan Aqoon — Online LIVE

Website multiplayer ah oo loogu talagalay TikTok LIVE. Ka qaybgalayaashu waxay ku soo galaan link, waxay doortaan Lab ama Dhadig, waxayna jawaabta xaqiijiyaan. Host-ku wuxuu arkaa leaderboard-ka live.

## Host controls
- Diyaar Garow: 1–60 ilbiriqsi
- Waqtiga Jawaabta: 5–300 ilbiriqsi
- START: bilaab tartanka
- PAUSE / SII WAD: jooji ama dib u bilow timer-ka
- STOP: jooji wareegga oo ku noqo lobby
- Su’aasha xigta: u gudub wareegga xiga

## Local test
1. Install Node.js 18+
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:3000`

## Online deployment
Ku deploy garee Node.js web service oo taageera WebSockets/Socket.IO. Build command: `npm install`. Start command: `npm start`.
